Stripe est un système de paiements par carte bancaire nécessitant une inscription préalable sur la plateforme Stripe.com

Pour installer Stripe sur votre course enduroller, voici ce qu'il faut faire :

- Inscrivez vous sur Stripe https://dashboard.stripe.com/register

- Suivez les étapes pour mettre vos informations bancaires, protéger votre compte, mettre les informations sur votre association, ou prouvez votre identité.

- les documentations suivantes peuvent être utiles : https://stripe.com/docs/account et https://stripe.com/docs/checklist

- Cherchez les clef d'API et copiez les dans les réglages de la course https://dashboard.stripe.com/account/apikeys dans les deux cases correspondantes.

- Installez le webhook quand c'est proposé ou cliquez sur le bouton ad-hoc
