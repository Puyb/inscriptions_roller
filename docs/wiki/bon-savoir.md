**Bon à savoir**
================



- Seul l’administrateur de la course peut supprimer une équipe.
- L’administrateur d’une course peut inscrire une équipe même si la course est fermée aux inscriptions ou si un critère est sensé bloquer les inscriptions comme le nombre maximum atteint dans une catégorie ou sur la course.
- Tout reste modifiable a tout moment comme les prix ou les catégories. Les changements seront appliqués aux équipes enregistrées avant la modification du critère en question si une modification est apportée à ladite équipe.
- Une question supplémentaire peut être mise en place après que des équipes se soient inscrites mais il faudra recontacter les équipes déjà inscrites avant le rajout de la question pour qu’elles y répondent car elles n’en seront pas averties par le site.
- Pour valider une autorisation parentale, il faut obligatoirement passer par la page de l’équipe concernée... pour l’instant.
- Pour l’envoi de mails multiples, il est possible de sélectionner seulement les équipes répondant à un critère horizontal et un vertical dans le tableau récapitulatif présent en haut de la page d administration en cliquant sur le nombre correspondant.
- Il existe une version test du serveur donc n’hésitez pas à aller sur le site test.enduroller.fr pour essayer les fonctions dont vous n’avez pas la maitrise.
