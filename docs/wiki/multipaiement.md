Le multipaiement

Certaines personnes payant pour plusieurs équipes : il a été mis en place une procédure simplifiée pour enregistrer ces paiements multiples par espèces, chèque ou virement.

Cette procédure s’applique pour toutes les courses ayant le même organisateur dont les inscriptions sont actives au moment où le multipaiement est enregistré sur enduroller. ( Permettant ainsi de valider le paiement d’une équipe sur plusieurs courses d’un challenge par exemple ).

Pour se faire, il faut se rendre dans le module "paiements" ( sur la page principale ) ( ou sur "ajouter un paiement" sur la page de gestion d’équipe puis «ajouter un paiement» en haut à droite et de remplir le formulaire.

Attention : la case commentaires présente sur ce formulaire ne correspond pas à la case commentaire de la page de gestion d’équipes et ne sera consultable que via le menu «paiements» et l’ouverture de la page du paiement concerné.

Pour valider un paiement, il faut que le «reste à répartir» soit égale à zéro sinon le lien de validation ne sera pas disponible.

Si le montant concernant une équipe est payé en intégralité, l’équipe passe automatiquement en équipe payée et le mail de paiement avec le lien de facture est envoyé automatiquement ( de la même manière qu'un paiement en ligne). ( Chaque équipe recevra le mail séparément avec le montant lié à son équipe validé).

Si une équipe n’a pas le montant totalement acquitté, le montant est déduit de l’inscription est le restant s’affichera sur les fiches de retrait de dossard. Le montant acquitté s’affiche également sur la fiche de gestion de l’équipe. L'équipe reste en non payée malgré un paiement partiel.

Il est donc possible qu’un chèque couvre x équipes intégralement et pas la dernière. Les x équipes seront ainsi «payées» et la dernière devra s’acquitter ultérieurement de la somme manquante. Elle rentre ainsi dans le cas de l astérisque précédente.
